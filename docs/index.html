Markdown to Word

A GitHub Action that converts Government of Canada Markdown documentation into professionally formatted Word documents using the SSC template.

Features

Built for the Government of Canada documentation workflow.

W

SSC template

Output uses the official SSC Word template with cover page, headers, and classification banner.

M

Mermaid diagrams

Render ```mermaid code blocks as embedded images — sequence, flowchart, class diagrams, and more.

→

Markdown → DOCX

Converts Markdown to Word with section numbering, page breaks, and a clickable table of contents.

T

Table of Contents

Place :::{#toc}::: in your Markdown and a static table of contents with hyperlink entries is generated.

¶

Page breaks

Use \newpage in your Markdown for precise control over page breaks in the output.

#

Classification header

Document classification (Unclassified, Protected A/B/C) is set in the header and document properties.

≡

Table formatting

Table cells are sized for readability with a compact 9pt font suited to technical documents.

+

Zero-config setup

Pandoc, Mermaid CLI, and Python dependencies are installed automatically in CI.

Usage

Add a step to your GitHub Actions workflow.

Basic usage • workflow.yml
- name: Convert Markdown to Word
  uses: bryanpaget/markdown-to-word@main
  with:
    default_title: "Incident Response Plan"
    markdown_file: "docs/incident-response.md"
    output_file:   "output/incident-response.docx"
With section numbering • workflow.yml
- name: Convert Markdown to Word
  uses: bryanpaget/markdown-to-word@main
  with:
    default_title: "Aurora Security Baseline"
    markdown_file: "docs/security-baseline.md"
    output_file:   "output/security-baseline.docx"
    number_sections: "true"

SSC Template

This action uses the official SSC Word template (ssc-template-v2.7.dotx) as the base for all conversions. The template provides:

● Cover page

Title, subtitle, date, version, and classification on a formal cover sheet.

● Headers & footers

Document title and classification repeated on every page.

● Fonts

Carlito (Calibri substitute) with Liberation Serif for headings — GC-compliant typefaces.

● Styling

Heading styles, table formatting, and list styles consistent with GC documentation standards.
